### 医学史等

**罗伊·波特《极简医学史》**：篇幅较短、较好入门。按疾病、医师、身体、治疗、医院等主题，概述西方医学史，也讨论医学与社会、文化和信仰的关系。适合先建立整体脉络。[书目信息与目录](https://baike.baidu.com/item/极简医学史/19443533)

**罗伊·波特主编《剑桥医学史》**：多位学者分专题撰写，覆盖疾病、医院、外科、药物及医学思想等，能看到医学史研究的广度。中文译本有译林出版社 2022 年版；复旦大学的相关课程也将它列为参考书。[课程参考书目](https://www.icourse163.org/course/FUDAN-1470843180)

**乔治·罗森《公共卫生史》**：医学社会史的重要经典，重点讨论城市化、工业化、贫困、国家治理和卫生改革如何影响公共健康。适合对流行病与社会制度的关系感兴趣的读者。[中文书评与内容介绍](https://m.bjnews.com.cn/detail/163427907514515.html)

**米歇尔·福柯《临床医学的诞生》**：经典理论著作，讨论现代临床医学知识、医院和医生观察方式如何形成。它的理论性较强，读起来比通史费力；可先读导言或配合导读。[南京大学相关研究介绍](https://ptextold.nju.edu.cn/f5/6f/c13354a587119/page.htm)

**威廉·麦克尼尔《瘟疫与人》**：从疾病传播与人类社会互动的角度讲世界史，适合了解传染病如何影响人口、文明交流和历史变迁。它更偏全球史和疾病史，可与公共卫生史搭配。[复旦大学课程参考书目](https://www.icourse163.org/course/FUDAN-1470843180)

**高晞主编《医学与历史》**：中文学界的医学史教材，适合想同时了解东西方医学发展、医学与社会文化关系的读者。复旦大学同名课程也以相关议题为主线。[课程介绍与参考书目](https://www.icourse163.org/course/FUDAN-1470843180)
